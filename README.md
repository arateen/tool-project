# ミニ便利ツール & ゲーム集

## 概要
コマンドライン上で動作する便利な計算機能やミニゲーム（じゃんけん・数当てゲーム等）をまとめた対話型ツールです。

## 利用したオープンソースソフトウェア（OSS）
- **rich** ([https://github.com/Textualize/rich](https://github.com/Textualize/rich))
  - **選定理由**: 通常の味気ない黒いコマンド画面を視覚的に分かりやすく装飾するため。
  - **活用箇所**:
    - `rich.panel.Panel`: じゃんけんや数当てゲームのタイトル枠、勝敗結果（勝ち・負け・あいこ）の枠線表示。
    - `rich.table.Table`: メニュー一覧を見やすい表形式でレイアウト。
    - **カラー装飾タグ**: 選択肢や勝敗メッセージを色分け（勝利は緑、敗北は赤、あいこは黄色）して直感的に表示。

## 動作環境と事前準備
- Python 3.x
- **外部ライブラリ（Rich）のインストール**:
  学内環境の場合は、プロキシを通す環境変数を設定した上でインストールを実行します：
```cmd
  set HTTP_PROXY=http://147.157.2.20:8080
  set HTTPS_PROXY=http://147.157.2.20:8080
  pip install rich
```

## 使い方
コマンドプロンプトで以下を実行します：

```cmd
python tool.py
```

メニュー番号を入力して各機能やゲームを起動します。

## Git/GitHub運用の工夫点
- 機能ごとにブランチ（`feature-janken`, `feature-rich-ui` 等）を切り替えて開発しました。
- ペア間でプルリクエストとコードレビューを実施してから `master` にマージしました。
- 並行開発に伴う競合（コンフリクト）を手動で解消しながら統合しました。
